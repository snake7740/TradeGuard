## 回放口径（诚实标注）

1. **无标签泄漏**：Class 标签仅用于事后对照，评分输入只有 Amount 与 Time；
2. **内核直调**：回放调用 AA-SK-01 确定性内核纯函数层（`score_signals` / `velocity_bonus` / `triage`，权重与 BA-BR-14 阈值原值），不经 PG/MCP 全链路（全链路由 110 例测试与 device-guard 场景覆盖）；
3. **维度缺口（诚实）**：V1-V28 为 PCA 匿名特征，本项目图维度（device/payee/ipseg）与外部源（征信/舆情/投诉）在数据集中不存在，不参与；
4. **主体缺口（诚实）**：无主体 ID → A 组 velocity 置零（tx 源权重 0.4 → 单信号评分上限 40），B 组以 30 秒时间邻接簇近似主体会话（card-testing 手法假设）；
5. **结论边界**：验证「骨架可消费公开数据分布、可映射维度指标可解释」，不对标 Kaggle 竞赛 SOTA（其直接消费 V1-V28 全量特征）。

## 结论

- A 组：金额单维信号在该数据集上接近无效（AP 0.0021 仅为随机基线 0.0017 的 1.2 倍）——ULB 欺诈以小额 card-testing 为主（欺诈金额中位 9.25 < 正常 22.00），金额维度天然不判别，如实披露；
- B 组：主体近似失效，如实披露：全流密度过高（全体中位邻接间隔 1.0 秒），5144/5456（94%）的簇都突破 BR-14 阈值——该阈值设计对象是「单主体」1h≥10 笔而非全市场流，欺诈落入率 95.7% 与正常 99.2% 几乎无差（lift 0.96x）。本数据集不具备验证主体级 velocity 规则的条件，需带主体 ID 数据集（如 Sparkov/PaySim，后续工作）；
- 本次回放证明：骨架可消费公开数据集（284,807 笔全量、无标签泄漏、内核原权重原阈值直调），可映射维度的业务指标（PR/告警队列规模/基线对照）可解释可复核；局限与负结果如实披露；
- 完整复现：`python scripts/dataset_replay.py`（数据下载见 `db/dataset/README.md`）。
