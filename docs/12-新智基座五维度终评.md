## 1. 评估方法与口径

- 打分对象：TradeGuard（交易风控中枢）作为「新智基座上的 Agent 应用」——
  评估的不是代码量，而是**场景真实、Agent 协同、Skill 复用、工程可信、开放可复现**五维。
- 每维度按"证据可得性"打分：无证据不给分，负结果如实披露不扣诚信分（方法学成熟度计正分）。
- 复现入口见 §5；所有测试在 PG16/pgvector + 双 MCP 实链路 + RocketMQ 降级矩阵下运行。
