## 1. 三个趋势判断

1. **LLM×图融合是学术主流，但 training-free 路线同步成熟**。旗舰工作（FLAG/GuARD/DGP）均为 LLM 增强 GNN，需训练；而 FreeGAD（CIKM25）、IA-GGAD（NeurIPS25）证明不训练也能获得有效图异常信号。**结论**：本方案"不采纳训练路线"（docs/09）继续成立，但应引入 training-free 图拓扑统计补强团伙识别。
2. **自反思与辩论式多 Agent 进入反欺诈/审计域**。SAGE（自反思 Agent 框架）、FraudDebate-Agent（辩论式审核）、AuditAgent（专家引导交叉审计）与本方案 planner 反思循环、R-47 互审、合规审计员岗位逐一同构。**结论**：协同层有学术先例支撑的深化空间，且无需改变"LLM 无决策权"边界。
3. **行业金标准是 per-entity 自适应基线；基础模型渗透交易序列但成本极高**。Featurespace ARIC 的核心是"每个实体自己的历史即基线"；PANTHER 等基础模型需海量真实交易预训练。**结论**：前者可规则版落地（直接回应 docs/12 主体级验证缺口），后者仅预留端口。
